#
# ...then:  pip install -r requirements-local.txt

# Must stay <1.0: transformers 4.57.x requires huggingface-hub<1.0,>=0.34.0, but the

# resolution fast and deterministic; it follows from the transformers<5 pin above, so
# these two move together.
